# TgEngin

（这一行留给一句话说清楚这台机器是什么。）

## 外面只有三个文件

| 文件 | 是什么 |
| --- | --- |
| `README.md` | 这份。 |
| `config.yaml` | 这台机器的配置。路径**一律相对这个文件所在的目录**，不是相对 cwd —— 从别的地方启动也开同一个库。 |
| `.env` | 号和钥匙。**不进版本库**（见 `.gitignore`），只在这台机器上。 |

别的东西都在子目录里。

## 跑

主要用 TypeScript。Node 24 直接吃 `.ts`，不用编译步骤：

```
node --version   # v24.14.0
```

## `.env` 里要有什么

```
DEEPSEEK_API_KEY=
DASHSCOPE_API_KEY=
```

缺了应当当场炸，并且说得出缺的是哪个键 —— 悄悄跑下去的话，
错会在很远的地方才冒出来。
